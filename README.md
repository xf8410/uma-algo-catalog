## 额外发现：NNUE 增量评估（不在 13 类里，但是金矿）

研究同组 hzyhhzy 的仓库时挖到一个 13 类清单之外、但对决策面至关重要的技术：**NNUE（高效可增量更新的浅网）**，见 `gomoku_nnue` / `BoardGameNNUE` / `KataGomo`。

- **原理**：局面走一步只变极少数特征，评估因此**只重算受影响的特征，其余共享**，不用全网络重跑。Stockfish 靠它在 CPU 上就快到飞起。
- **为什么对我们重要**：GBDT 叶子评估器要吃的 754 维状态，MCTS 每走一步其实只动几个维度（体力 −5、心情 +1 这种）。用 NNUE 的增量思路，能把「每步遍历几百棵树」压成「只重算变动的特征路径」——这是把 GBDT 从“便宜”再压到“又快又便宜”的关键。
- **归属**：这不是新的“优化器”，是给 GBDT 叶子评估器（05 族下一棒）加的一道增量优化，待设计稿落地。
