# 第 6 族：黑箱系统辨识 / 动态建模

> 一句话：这批算法干的是"从观测数据反推系统背后的动力学方程"——比如给一堆"状态怎么随时间变"的数据，反推出支配它的微分方程。

**整族对赛马娘的结论**：🚫 **判定不适用，不再回头。** 核心原因一句话——**我们的模拟器是白盒可读的**，内部逻辑能从源码/IL2CPP dump/master.mdb 实测抓到，根本不需要"从数据反推方程"。系统辨识是给"真黑盒、看不到内部"的系统用的功夫，我们不是这个情况。

---

## SINDy / PDE-FIND / EQL

- **干什么用**：SINDy 从时间序列数据里用稀疏回归挑出"哪几个项在起作用"，重建微分方程；PDE-FIND 是偏微分版；EQL 是符号回归神经网络版。
- **怎么调**：候选函数库（候选项表达式集合）、稀疏度惩罚 λ。
- **怎么提升**：数据干净、系统低维时能还原出可解释方程。
- **对赛马娘帮助**：🚫 不适用。育成机制公式可直接读源码，无需重建。

## Neural ODE / UDE（通用微分方程）

- **干什么用**：把神经网络的输出当成"动力学方程的导数"，让 NN 和数据一起学出连续动力学模型。
- **怎么调**：ODE 求解器、NN 结构、端到端可微求解。
- **怎么提升**：适合连续时间的物理/动力系统。
- **对赛马娘帮助**：🚫 不适用。育成是离散回合动作，不是连续动力学。

## HNN / LNN（哈密顿/拉格朗日神经网络）

- **干什么用**：把物理守恒结构（能量守恒 HNN / 拉格朗日 LNN）硬编码进网络，学出来的模型自动遵守物理规律。
- **怎么调**：网络结构 + 守恒约束项。
- **怎么提升**：适合机械/能量守恒系统，泛化好。
- **对赛马娘帮助**：🚫 不适用。没有可硬编码的守恒物理结构。

## Koopman 算子 / DMD / EDMD / Koopman MPC

- **干什么用**：把非线性系统"升维"到一个线性空间，用线性算子刻画演化，再做控制（MPC）。
- **怎么调**：观测函数（升维特征）设计、回归方式。
- **怎么提升**：能把非线性控制问题线性化，是控制理论里很漂亮的一套。
- **对赛马娘帮助**：🚫 不适用。理由同上，模拟器白盒 + 无显式动力学需求。

## 族总结

| 状态 | 结论 |
|---|---|
| 🚫 整个族不适用 | 模拟器是白盒（源码可读），不需要从数据反推动力学 |
