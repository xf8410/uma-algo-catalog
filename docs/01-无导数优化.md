# 第 1 族：无导数优化 DFO

> 一句话：这批算法都不问你要"梯度"（函数长啥样的斜率），只靠"试几个点、看哪个好、往好的方向挪"来爬山。适合拿不到导数、或者导数算不准的黑盒函数。

**整族对赛马娘的结论**：Powell 已经替这族踩过雷——在"离散参数 + 噪声评分"的景观里，经典 DFO 跑不过进化系（第一梯队赛马垫底 -601 退出）。本族其余变体大概率同结局，只有遇到"精确要某个局部精修"的小问题才值得再翻出来。

---

## NEWUOA / LINCOA / UOBYQA（Powell 信赖域插值三兄弟）

- **干什么用**：在若干采样点上拟合一个二次曲面（近似函数局部形状），在信赖域内找这曲面的最低点，逐步迭代。NEWUOA 无约束、LINCOA 带线性约束、UOBYQA 带二阶信息。
- **怎么调**：核心是"插值点数"和"信赖域半径"两点；插值点多→曲面准但算得贵，半径大→步子大但可能翻车。默认 2n+1 个插值点起步。
- **怎么提升**：问题光滑连续时效率极高；问题带噪声或参数是离散档位时，二次曲面拟合会失真，此时不如进化系。
- **对赛马娘帮助**：⬜ 基本不用。70 个旋钮大多是离散档位 + 评分带噪声，正是它最不擅长的场景。Powell 已退出，这三兄弟留档案。

## MADS / GSS / PSD-MADS（网格自适应搜索族）

- **干什么用**：在参数空间铺一张网格/方向集，逐个方向试探，找不到更好的就加密再探。MADS 的自适应是把密集搜索方向随时间扩散。
- **怎么调**：试探步长和方向集密度；步长大收敛快但粗糙，步长小精细但慢。
- **怎么提升**：对小维度、无噪声问题稳；对高维（我们 47 维）和噪声问题，网格会被噪声带偏。
- **对赛马娘帮助**：⬜ 不用。47 维网格爆炸，效率低。

## Implicit Filtering（隐式滤波）

- **干什么用**：用差分近似梯度 + 逐步减小差分步长，等价于"先在高噪声下粗找方向，再降噪精细爬"。
- **怎么调**：差分步长的衰减速度；太快容易陷局部，太慢浪费评估。
- **怎么提升**：适合能控噪声、有近似梯度的连续问题。
- **对赛马娘帮助**：⬜ 不用。评分噪声大且不可控，差分方向会被噪声淹没。

## SID-PSM / DFO-LS / ORBIT / APPSPACK / HOPSPACK

- **干什么用**：SID-PSM 子空间拟牛顿、DFO-LS 无导数最小二乘、ORBIT 径向基插值信赖域、APPSPACK/HOPSPACK 大规模异步并行搜索框架。
- **怎么调**：各有所长，但共同点是针对连续光滑或大规模并行场景。
- **怎么提升**：ORBIT 用径向基（RBF）当代理，比二次插值更耐不规则；APPSPACK/HOPSPACK 靠并行堆评估次数换速度。
- **对赛马娘帮助**：⬜ 不用。我们已有多优化器 + CI 并行，这族的并行框架优势已被覆盖。

| 结论 | 说明 |
