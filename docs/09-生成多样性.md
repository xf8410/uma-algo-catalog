# 第 9 族：生成与多样性

> 一句话：这族是"生成模型"——学会数据的分布，然后能造出新的、多样的样本（图片、动作等）。

**整族对赛马娘的结论**：🚫 **判定不适用。** 核心原因——**生成数据不是我们的瓶颈**，5.6 万局真数据已经够用。生成模型的价值在"真数据稀缺要造合成数据"的场景，而我们不缺数据。

---

## VAE / CVAE / VQ-VAE

- **干什么用**：变分自编码器，把输入压成隐向量再重建，从而能采样生成新样本；CVAE 加条件（指定类别生成），VQ-VAE 用离散码本。
- **怎么调**：隐维度、β（重构 vs KL 的权衡）、码本大小。
- **怎么提升**：生成多样性样本的主力；CVAE 能做条件生成。
- **对赛马娘帮助**：🚫 不适用。不缺数据，且黑盒评估下没有"生成新状态"的需求。

## Normalizing Flows 族（RealNVP / Glow / MAF / IAF）

- **干什么用**：可逆神经网络，把简单分布"流"成复杂分布，能精确算概率密度、采样。
- **怎么调**：流层数、耦合结构。
- **怎么提升**：密度估计精确，生成质量高。
- **对赛马娘帮助**：🚫 不适用，同上。

## Flow Matching / Rectified Flow / Consistency Models

- **干什么用**：新一代生成范式——不学扩散的随机路径，直接学"从一个分布到另一个分布的直线最优传输"，采样更快。
- **怎么调**：路径选择、采样步数。
- **怎么提升**：比扩散更快收敛/采样，是生成领域的前沿。
- **对赛马娘帮助**：🚫 不适用，同上。生成不是瓶颈。

---

## 族总结

| 状态 | 结论 |
|---|---|
| 🚫 整个族不适用 | 真数据 5.6 万局够用，生成数据无需求 |
| 唯一例外 | 若未来"质量多样性"要造多样化策略（MAP-Elites + VAE），那是锦上添花，非正事 |
