## 1. 无导数优化 DFO

| 算法 | 状态 | 备注 |
|---|---|---|
| NEWUOA / LINCOA / UOBYQA | ⬜ | Powell 的信赖域二次插值亲戚；Powell 已实验垫底，这类可走 Powell 的档案结论 |
| SID-PSM / DFO-LS | ⬜ | 极小化平方/最小二乘的 DFO，连续光滑空间专用 |
| MADS / GSS / PSD-MADS | ⬜ | 网格/模式搜索，无梯度爬山，收敛慢 |
| Implicit Filtering / ORBIT / APPSPACK / HOPSPACK | ⬜ | 隐式滤波 + 大规模并行 DFO 工具集 |

**族级结论**：Powell 已代表"经典 DFO 在离散+噪声景观打不过进化系"（垫底 -601 退出），本族其余变体大概率同结局，除非有具体子问题需要精确局部精修。
