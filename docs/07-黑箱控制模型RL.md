# 第 7 族：黑箱控制 / 基于模型 RL

> 一句话：这族算法先学一个"世界模型"（模拟器/环境的替身），再在这个模型里规划或强化学习——目的是省掉"真环境里试错"的成本。

**整族对赛马娘的结论**：🚫 **判定不适用。** 核心原因——**我们已经有真模拟器**（一局几秒，可以大量重放），再去学一个世界模型是负收益（费劲学出来的模型肯定不如真模拟器准）。这族的价值在"没有真模拟器、只能靠数据猜环境"的场景，我们恰好站在反面。

---

## PILCO / GP-MPC / Black-DROPS

- **干什么用**：用 GP 学系统动力学 → 用模型做控制或规划；PILCO 是"模型+策略联合优化"，GP-MPC 是 GP 模型+模型预测控制，Black-DROPS 是黑盒鲁棒控制的贝叶斯版。
- **怎么调**：GP 核、预测时域、正则化。
- **怎么提升**：真环境昂贵/危险时，用模型替代试错，样本效率极高。
- **对赛马娘帮助**：🚫 不适用。真模拟器就是最强的"模型"，学 GP 模型是降级。

## PETS / MBPO

- **干什么用**：PETS 用集成概率模型做采样规划（CEM 在模型里挑动作）；MBPO 用模型生成短幻觉 rollout 混合真数据训练策略。
- **怎么调**：模型集成数、roollout 长度（MBPO 的短 rollout 是关键）。
- **怎么提升**：在 MuJoCo 等真环境贵的任务上是经典 Basline。
- **对赛马娘帮助**：🚫 不适用。我们的"模型"就是模拟器本体，MBPO 的幻觉 rollout 等于不用模拟器反而用个弱的替身。

## PlaNet

- **干什么用**：学一个隐空间世界模型，直接在隐空间里做规划和想象。
- **怎么调**：隐空间维度、模型结构。
- **怎么提升**：长期规划任务样本效率高。
- **对赛马娘帮助**：🚫 不适用。

---

## 族总结

| 状态 | 结论 |
|---|---|
| 🚫 整个族不适用 | 我们"有真模拟器"（一局几秒可重放），学世界模型是负收益 |
| 相关但有区别 | "MPC 前瞻"我们已经在走，但那是**用真模拟器快进**（flat_search），不是学模型 |
