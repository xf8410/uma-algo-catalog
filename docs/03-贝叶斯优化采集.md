# 第 3 族：贝叶斯优化采集函数与变体

> 一句话：贝叶斯优化（BO）的思路——先建一个"哪个参数区间可能出高分"的概率模型（代理），再用"采集函数"决定下一次试哪。这一族就是各种"决定下一试点"的策略。

**整族对赛马娘的结论**：TPE（BO 的一种实现）已是四选手之一，但"评估一次要跑分钟级模拟"正是 BO 的主场。采集函数本体大多没逐个试，真正排队的是多目标版（qEHVI/ParEGO，tier2 #9）。

---

## 一、单目标采集函数（经典四件套）

### EI 期望改进
- **干什么用**：算"新点比当前最好高多少的期望"，挑期望最大的点试。
- **怎么调**：EI 有个"探索/利用"权衡项 ξ；ξ 大更爱探索，ξ 小更爱利用。
- **怎么提升**：最常用的默认选择，能自动平衡探索利用。
- **对赛马娘帮助**：⬜ 未单独试（TPE 内部逻辑相近，已覆盖）。

### PI 改进概率
- **干什么用**：只关心"新点能不能超当前最好"，不关心超多少。
- **怎么调**：阈值 τ；设成略高于当前最好能鼓励探索。
- **怎么提升**：简单但容易陷入局部（只看"过没过线"不看过多少）。
- **对赛马娘帮助**：⬜ 未试，非优先。

### UCB / KG
- **干什么用**：UCB=均值+置信区间上界，直接挑"可能最高"的点；KG（知识梯度）算"这一点带来的全模型知识增量"。
- **怎么调**：UCB 调探索系数 β；KG 是全局收益更聪明但计算重。
- **怎么提升**：UCB 好算通用；KG 在噪声评估下更稳但贵。
- **对赛马娘帮助**：⬜ 未试（作为"预算分配"思想，UCB 在 tier2 #7 有同族落点）。

## 二、熵搜索族（信息量优先）

### Entropy Search / PES / MES / JES
- **干什么用**：不挑"可能最高"，而是挑"最该探哪里能最大降低对最优解位置的不确定性"。
- **怎么调**：这些方法计算都贵，需要采样近似；核心是熵的估计精度。
- **怎么提升**：对"想知道全局最优在哪"的问题理论上更优，但实现复杂、算得慢。
- **对赛马娘帮助**：⬜ 未试。评估贵 + 批次小的场景，EI/TPE 已经够用，熵搜索性价比低。

## 三、并行批量：qEI

- **干什么用**：一次算出一整批（q 个）点的联合期望改进，支持并行评估。
- **怎么调**：批次大小 q。
- **怎么提升**：有并行算力时能同时跑多点。
- **对赛马娘帮助**：⬜ 未试（我们的 CI 并行已由调度层管，采集函数层不需要并行贪心）。

## 四、多目标 BO（同时优化平均分和风险）

### qEHVI / qNEHVI / ParEGO / qParEGO
- **干什么用**：同时优化多个目标（如 mean 分数 + CVaR 风险），产出 Pareto 前沿让你选风险口味。
- **怎么调**：EHVI 调超体积参考点；ParEGO 用随机标量化把多目标变成单目标。
- **怎么提升**：qNEHVI 比 qEHVI 更抗噪；ParEGO 最省实现。
- **对赛马娘帮助**：🔄 **排队（tier2 #9）**。CVaR 已有单目标版，MOBO 是它的自然升级——但因为要把"高平均分"和"低风险"一起画前沿，成本中高（botorch），先排队。

### MOEA/D-EGO / SMS-EGO / USeMO / DGEMO / TSEMO / BMO / CoCaBO
- **干什么用**：多目标 BO 的实现变体（分解式、S度量、顺序式、上下文式等）。
- **怎么调**：各持一个标量化/分解策略，多目标最近想上时按实现复杂度挑。
- **怎么提升**：这些主要是"多目标 BO 的工程实现"差异，算法思想同 EHVI/ParEGO。
- **对赛马娘帮助**：⬜ 未试，多目标需求落地时再选型。

## 五、组合/离散/分类空间 BO

### CASMOPOLITAN / BOCS / COMBO
- **干什么用**：在"离散/组合/类别型"参数空间上做 BO（不用连续假设）。
- **怎么调**：BOCS 用二次模型，COMBO 用组合图模型，CASMOPOLITAN 处理混合变量。
- **怎么提升**：我们参数有离散档位，这族理论上更对症。
- **对赛马娘帮助**：⬜ 未试。参数面离散化了，若 TPE 在离散映射上不够好，BOCS/COMBO 是备选。

## 六、高维 BO

### REMBO / HeSBO / ALEBO
- **干什么用**：把高维问题映射到低维子空间里做 BO，再映射回来。
- **怎么调**：子空间维度 d 和映射方式；d 越小越省但可能漏最优。
- **怎么提升**：BO 经典在 20-50 维内有效，更高就靠降维。
- **对赛马娘帮助**：⬜ 未试。47 维在 BO 可用边界，暂不需降维；维度再涨才考虑。

## 七、学习式 / 自适应 / 约束 BO

### BORE
- **干什么用**：把采集函数变成"好/坏二分类"问题，用 LightGBM 分类器来算"这个点好不好"的概率。
- **怎么调**：分类器阈值（top 多少算好）、GBDT 超参。
- **怎么提升**：TPE 的表亲但用 GBDT，对混合离散空间可能比 optuna 默认更对症。
- **对赛马娘帮助**：⬜ tier1 候选，未单独收账。跟 GBDT 叶子同技术栈，值得单独评估。

### LFBO（学习式采集）
- **干什么用**：用另一个模型学"EI 本身"，把采集函数也学习出来。
- **怎么调**：学习目标和采样分布。
- **怎么提升**：采集函数"多少算最优"本身是个研究问题，LFBO 端到端学。
- **对赛马娘帮助**：⬜ 未试，偏前沿，非优先。

### SCBO / CBO（约束 BO）
- **干什么用**：在"有硬约束"的情况下做 BO（比如参数必须满足某范围或组合条件）。
- **怎么调**：约束的代理模型和可行性概率阈值。
- **怎么提升**：我们的约束（卡卡组、马娘不能带本体卡）能不能建模？部分可。
- **对赛马娘帮助**：⬜ 未试。若把"非法卡组"当硬约束建模，SCBO 能少踩雷；但当前是事后剔卡，暂不需。

### ALBO（自适应 BO）
- **干什么用**：自动在多个采集函数/代理之间切换，不用人挑。
- **怎么调**：候选池和切换策略。
- **怎么提升**：省心但实现重。
- **对赛马娘帮助**：⬜ 未试，非优先。
