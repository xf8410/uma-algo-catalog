# 第 5 族：代理模型与不确定性

> 一句话：BO 要靠一个"代理模型"来猜评分函数长啥样，这一族就是各种代理模型——从老派的 GP 到现代的贝叶斯神经网络，核心是"不仅猜一个值，还猜这个值有多不确定"。

**整族对赛马娘的结论**：代理模型是 BO 的发动机，但 TPE 已经用一个极简代理（分位数树）跑起来了；真正的主角是 **GBDT 当叶子评估器（tier3 #10）**——它既是代理，又是决策面的估值器，是下一棒。

---

## 轻量代理（TPE 已经在用的范式）

### 分位数回归 / 共形预测
- **干什么用**：分位数回归直接估计"分数的某个分位数"（如 80% 分位），不假设正态；共形预测给出"真实值有多大概率落在这个区间"。
- **怎么调**：分位数 τ 的选择；共形预测的校准集大小。
- **怎么提升**：对厚尾、噪声评分比"只估均值"更稳。
- **对赛马娘帮助**：⬜（思想已被 TPE 的分位数模型 + CVaR 适应度部分覆盖）。

## GP 系代理

### 高斯过程 GP / 稀疏 GP / 变分 GP
- **干什么用**：GP 把未知函数假设成一个随机过程，给出任意点的"均值 + 不确定度"；稀疏/变分版是为了让 GP 在大数据量下算得动。
- **怎么调**：核函数（RBF/Matern）、长度尺度、噪声假设。
- **怎么提升**：小样本（<几百点）时 GP 是最优美的不确定性模型；数据一多就贵。
- **对赛马娘帮助**：⬜ 未试主用。评估一次几分钟、预算几十上百次——GP 其实够用，但 TPE 更省事已经上位。

### 随机傅里叶特征 / Nystrom
- **干什么用**：给 GP 做近似，把核矩阵降维，让 GP 能上规模。
- **怎么调**：特征数量 / 采样点数。
- **怎么提升**：GP 的"穷人版加速"。
- **对赛马娘帮助**：⬜ 未试，非优先。

## 贝叶斯神经网络系

### 贝叶斯 NN / MC Dropout / 深度集成 / SWAG / Laplace
- **干什么用**：让神经网络也会"报不确定度"——贝叶斯 NN 把权重当分布；MC Dropout 用 dropout 在推理时采样；深度集成训练多个模型投票；SWAG/Laplace 是近似贝叶斯的便宜招。
- **怎么调**：集成个数 / dropout 率 / 采样次数。
- **怎么提升**：比 GP 更擅长高维（754 维），是 NN 决策器的"带不确定性"升级。
- **对赛马娘帮助**：⬜（深度集成：上游 NN 侧已有 export_ensemble_onnx）。若决策面 NN 需要"这局面评估靠不靠谱"，深度集成是现成路。

### 神经过程 NP / 条件神经过程 CNP
- **干什么用**：一个"会学习的 GP"——吃点-数据就输出函数分布，天生支持元学习。
- **怎么调**：上下文点数量、编码器结构。
- **怎么提升**：能跨任务迁移不确定性先验。
- **对赛马娘帮助**：⬜ 未试，偏前沿。

## 深度核学习

- **干什么用**：把 NN 学出的特征喂给 GP，兼得 NN 的表达力和 GP 的校准不确定性。
- **怎么调**：NN 结构 + GP 核权重联调。
- **怎么提升**：高维 + 不确定性兼顾的方案。
- **对赛马娘帮助**：⬜ 未试。754 维若走 GP 路线，这是正确姿势，但重。

## 特别强调：GBDT 当代理/叶子评估器

- **干什么用**：用梯度提升树（XGBoost/LightGBM）学"看状态报分"。纯 Rust/高效遍历、零依赖、不用 GPU、不用批量，754 维 × 几百棵树推理极快。
- **怎么调**：树数、最大深度、学习率、叶子数、特征采样。
- **怎么提升**：5.6 万局对 NN 偏少，但对 GBDT 很够；推理比 NN 快一个量级。
- **对赛马娘帮助**：🔄 **下一棒主角（tier3 #10）**。接 flat_search 空叶子，把 MCTS 空转的前瞻补上。图1 已经论证它恰好消掉 NN 当年的三个工程死穴（单样本前向慢、要 GPU、值头偏差）。
- **NNUE 增量升级**：GBDT 每步只改几个维度，用 NNUE 的"增量更新"思路，可把"每步遍历几百棵树"压成"只重算受影响特征路径"——见 README 的 NNUE 一节。
