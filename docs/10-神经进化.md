# 第 10 族：神经进化 / 进化编程

> 一句话：这族用进化算法去"进化出神经网络的结构本身"（几层、几条连接），而不是固定好结构只训权重。

**整族对赛马娘的结论**：🚫 **判定不适用。** 核心原因——**我们的网络结构是固定的 754 维编码**，决策面和评估器的输入输出早就定死了。搜索拓扑带来的收益微乎其微，而成本极高（进化出结构要海量评估）。

---

## NEAT / HyperNEAT / CPPN / ES-HyperNEAT

- **干什么用**：NEAT 从零进化出网络拓扑（节点和连接一起进化）；CPPN 用"复合模式生成网络"来编码大网络；HyperNEAT 用 CPPN 生成网络权重的规则。
- **怎么调**：NEAT 的种群大小、物种划分、连接突变率；CPPN 的激活函数组合。
- **怎么提升**：拓扑结构对任务影响大、且未知时，NEAT 能自己长出合适的结构。
- **对赛马娘帮助**：🚫 不适用。输入输出固定，结构无探索空间。

## Cartesian GP / Linear GP / PushGP

- **干什么用**：进化"程序/表达式"——CGP 进化网格上连线的计算图，Linear GP 进化指令序列，PushGP 进化栈式语言程序。
- **怎么调**：网格大小、变异率、函数集。
- **怎么提升**：当解是"一小段可执行逻辑"而非"一组权重"时对口（符号回归、自动编程）。
- **对赛马娘帮助**：🚫 不适用。我们不是"进化程序"，是"训 754 维固定网络 + 调 70 个参数"。
